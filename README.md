# PYS

一个单文件 C++ 控制台小游戏 demo:在 128 x 32 的地图里移动、采集资源,右侧信息栏实时显示状态,方向键可以切到商店场景。

仅作学习性质的 demo,用 Windows 控制台 API 直接绘制,无第三方依赖。

## 运行

需要 Windows + MinGW g++(或 MSVC)。

```powershell
g++ -std=c++17 -O2 test.cpp -o PYS.exe
./PYS.exe
```

VS Code 用户可直接使用仓库内的 `.vscode/tasks.json` 构建(任务:`C/C++:g++.exe build active file`)。

程序会自己设置控制台缓冲区大小并隐藏光标,运行时需要独占一个控制台窗口。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `A` / `S` / `D` | 移动 `@` |
| `E` | 采集脚下的资源(该位置的 `#` 消失,计数 +1) |
| `→` | 切到商店场景 |
| `←` | 切回游戏场景 |
| `Q` | 在游戏或商店场景退出 |

## 已实现

- 单缓冲逐格重绘的控制台渲染:移动时擦除旧位置、绘制新位置,资源点在采集时才清除。
- 非阻塞输入,基于 `GetAsyncKeyState`,主循环 30ms 一帧,所以长按可以连续移动。
- 资源随机分布,密度约 6%;地图剩余资源降到 50 或以下时自动补一波,采集和补充会即时更新剩余计数。
- 右侧信息栏(第 129 列起)显示坐标、已采集数、剩余资源数与操作提示。
- 场景状态机:`scene` 为 0 时是采集场景,为 1 时是商店场景。
- 只在场景发生变化时清屏,回到游戏场景时重绘现有资源;长按方向键不会重复清屏。
- 地图数组、资源生成与移动统一使用 128 x 32 的边界;信息栏占第 129 ~ 224 列,每行覆盖输出以避免数字残留。
- 通过修改窗口样式禁用拖拽和最大化,避免拉伸破坏固定尺寸的绘制布局。
